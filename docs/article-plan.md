### A1. 週5の正社員じゃない人の育児休業給付金（パート・シフト・週3・時短・契約社員）
- 検索意図: 「育休手当 パート / 週3 / 時短 もらえる」
- 要点:
  - 11日要件は出勤“日数”ではなく「賃金支払基礎日数」。週3でも月11日を超える月はカウントされる
  - 月11日に届かない月は「80時間ルール」（2020-08以降）で救済され得る → 時短・短日数勤務の人ほど重要
  - 雇用保険に加入しているか（週20時間以上等）が大前提
  - 有給休暇の日も賃金支払基礎日数に入る
- 見出し: H2 正社員前提の解説の落とし穴 / H2 「日数」でなく「賃金支払基礎日数」 / H2 11日に届かない月の80時間ルール / H2 ケース別シミュレーション / H2 あなたの勤務形態で判定する（ツール）
- ツール導線: 勤務日数を入れて月ごとの判定を見る
- 関連: B2(80時間), B3(有給vs欠勤), P0

### A2. 「2年→最長4年」延長の正確な仕組み（よくある誤解を正す）
- 検索意図: 「育休 給付金 2年 4年 延長 / 緩和」
- 要点:
  - 誤解「出産前◯ヶ月まで遡れる」ではない。正しくは「賃金の支払いを受けなかった休業（産休・育休・病気休職など）が連続30日以上あると、その日数ぶんだけ判定対象の2年窓が過去へ延びる（合計最長4年=加算上限730日）」
  - 賃金が支払われた休業は加算対象外
  - 連続30日未満のブロックは加算されない／重なる休業は1つの連続期間として合算
  - 具体例: 産休98日+育休…で窓がどれだけ延びるか
- 見出し: H2 よくある誤解 / H2 正しい仕組み（無給休業×連続30日×日数加算） / H2 加算されないケース / H2 数値例 / H2 自分の休業履歴で計算する（ツール）
- ツール導線: 休業期間を入れて延長後の窓を見る
- 関連: A3, B5, P0

### A3. つわり・妊娠中の休みが受給条件を崩す“落とし穴”（と、逆に味方になる条件）
- 検索意図: 「つわり 休職 育休手当 / 妊娠 欠勤 もらえなくなる」
- 要点:
  - 落とし穴: つわりで無給欠勤すると、その月の賃金支払基礎日数が11日未満になり「条件未達」になり得る
  - 回避: 有給休暇を充てれば賃金支払基礎日数にカウントされる（条件達成に有利）
  - 逆転: 無給の休み（病気休職等）が連続30日以上なら、緩和（窓延長）の対象になりプラスに働く
  - つまり「有給か無給か」「連続30日に届くか」で結果が分岐する繊細さ
- 見出し: H2 なぜ条件が怪しくなるのか / H2 有給を使う/使わないの分かれ道 / H2 連続30日以上なら緩和対象に / H2 ケース別早見 / H2 自分の休みパターンで判定（ツール）
- ツール導線: 休職・欠勤を入れて結果の変化を見る
- 関連: A2, B3, P0

### ☆高優先（落とし穴クラスター）

### B1. 転職して育休、前職の期間は通算できる？（失業給付を受けるとリセットされる落とし穴）
- 要点: 前職と現職の被保険者期間は一定条件で通算できるが、離職後に失業給付（基本手当）の受給資格決定を受けると、それ以前の期間は通算対象外になる。空白期間の扱い。
- ツール導線: 前職セグメントと基本手当受給の有無を入れて通算結果を見る
- 出典: 業務取扱要領 §4-1イ/§4-2（要確認）

### B2. 月11日に届かない月の救済「80時間ルール」とは（2020年8月から）
- 要点: 賃金支払基礎日数が11日未満でも、賃金支払の基礎となった時間が80時間以上ならその月をカウント。2020-08-01以降の月にのみ適用。時間の記録が必要。
- ツール導線: 時間入力して80時間ルールでの判定を見る

### B3. 「賃金支払基礎日数」の正しい数え方（有給・欠勤・公休・休業手当）
- 要点: work / 有給 / 休業手当（労基26条）はカウント、欠勤（無給）はカウントしない、公休（土日祝）は元々対象外。間違えやすい区分を表で。
- 関連: A1, A3

### B4. 出産予定日がぶれると「もらえる/もらえない」が変わる理由
- 要点: 育休開始日は出産日が起点（出産日＋産後56日＋1日）。出産日がずれると判定対象の2年窓ごと動くため、ぎりぎりの人は数日の差で可否が変わる。ツールの1日刻みスキャンの核心。
- ツール導線: 出産予定日の前後を1日ずつ判定

### B5. 産休・育休そのものが次の受給に効く（産休は無給＝緩和対象／出産手当金は「賃金」ではない）
- 要点: 産休中は通常無給なので緩和（窓延長）の対象。出産手当金・育児休業給付金は「賃金」ではないため hasWageDuringLeave の判定に注意。
- 関連: A2

### B6. 最後の“端数月”の扱い（15日ルールと0.5カウント）
- 要点: 完全月で割り切れない端数月は、15日以上ありかつ賃金支払基礎日数11日以上なら0.5か月としてカウント。15日未満は対象外。ぎりぎりの人の最後の1押し。

### B7. 産後すぐ取らず、数か月後に育休を取る場合（育休開始日のズレと窓のズレ）
- 要点: 育休開始日を後ろにずらすと、判定対象の2年窓も後ろにずれる。会社と確定日が決まっているケースの注意。ツールの育休開始日カスタム指定。

### B8. 双子以上（多胎妊娠）の場合の違い
- 要点: 産前休業が42日→98日に。育休開始日の起点計算に影響し、判定にも波及。
