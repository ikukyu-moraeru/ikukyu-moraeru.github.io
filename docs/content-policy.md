# コンテンツポリシー

最終更新日：2026-08-25

本ページは「育休もらえる？」（以下「本サービス」）のコンテンツポリシーを定めます。

---

## 1. サービス概要

本サービスは、日本の **育児休業給付金（雇用保険）** の受給要件をブラウザ上でセルフ判定できる無料ツールです。

判定結果を確定回答として示すのではなく、受給条件が微妙な方が見落としやすい月や記録を発見し、勤務先・ハローワークへ相談する準備を整える判断支援を目的とします。

- 対象者：育休給付金の受給可否が微妙な方（転職・休職・シフト制・パート等）
- 技術：静的ウェブアプリ（React + TypeScript）、サーバーレス
- 入力データはすべてブラウザ内で完結し、外部送信は行いません

---

## 2. コンテンツの性質

| 項目 | 内容 |
|------|------|
| 言語 | 日本語 |
| カテゴリ | 法律・社会保障 / 妊娠・育児 / 行政手続き |
| 対象読者 | 日本在住の妊娠中・育休取得予定の方、その家族 |
| コンテンツ形式 | インタラクティブ判定ツールと、一次情報に基づく少数の解説記事 |

### 制度記事の公開基準

公開する制度記事は、対象者、適用条件、このページだけでは判断できない範囲、一次情報の確認日、具体的な相談先を明示します。主要な制度上の主張は厚生労働省・ハローワーク等の一次資料に結び付け、運営者が判定ロジックとの整合を確認します。

制度改正や一次資料の更新を把握した場合は該当記事を見直します。正確性を確認できない記事、他の記事と重複して独自の判断材料を提供しない記事は、公開停止または中核記事への統合を行います。

---

## 3. 掲載しないコンテンツ

本サービスは以下のコンテンツを掲載しません。

- アダルト・性的なコンテンツ
- 暴力・差別的な表現
- 違法行為を助長する情報
- 虚偽・誇大な医療・法律情報
- ギャンブル・賭博関連コンテンツ
- 危険物・武器関連コンテンツ
- 政治的な主張・選挙運動

---

## 4. 広告・商品リンクに関するポリシー

### 4-1. 掲載する商品リンク

本サービスは Amazonアソシエイト・プログラムを利用し、記事、トップページ、判定結果の内容に関連する商品へのアフィリエイトリンクを掲載します。

### 4-2. 商品の選定

商品は、制度を確認するための参考書籍や、申請書類・勤務記録の整理に役立つものを運営者が選定します。商品の購入は、受給条件や申請手続きの要件ではありません。

### 4-3. 商品リンクの配置

商品リンクは記事末、トップページ末尾、判定結果の免責事項後に配置し、「広告・Amazonアソシエイトリンク」と明示します。コンテンツの可読性を妨げず、本文や判定結果と混同されないよう視覚的に区別します。ツールの入力途中や判定結果より前には配置しません。

### 4-4. Amazonアソシエイトの開示

Amazonのアソシエイトとして、育休もらえる？は適格販売により収入を得ています。

商品リンクをクリックした後のデータの取り扱いについては、[Amazon.co.jp プライバシー規約](https://www.amazon.co.jp/gp/help/customer/display.html?nodeId=201909010) をご覧ください。

## 5. 著作権・引用について

本サービスが参照している法令・制度情報は、厚生労働省・ハローワークの公的情報に基づいています。判定ロジックの根拠となる情報源は `Rule.md` に記載しています。

## 6. 免責事項

本サービスの判定結果はあくまで参考情報です。育児休業給付金の受給可否は最終的にハローワーク（公共職業安定所）が判断します。本サービスの利用によって生じたいかなる損害についても、運営者は責任を負いません。
