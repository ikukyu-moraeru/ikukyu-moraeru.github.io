# コンテンツポリシー（Google AdSense 向け）

最終更新日：2026年4月27日

本ページは「育休もらえる？」（以下「本サービス」）のコンテンツポリシーを定めます。

---

## 1. サービス概要

本サービスは、日本の **育児休業給付金（雇用保険）** の受給要件をブラウザ上でセルフ判定できる無料ツールです。

- 対象者：育休給付金の受給可否が微妙な方（転職・休職・シフト制・パート等）
- 技術：静的ウェブアプリ（React + TypeScript）、サーバーレス
- 入力データはすべてブラウザ内で完結し、外部送信は行いません

---

## 2. コンテンツの性質

| 項目 | 内容 |
|------|------|
| 言語 | 日本語 |
| カテゴリ | 法律・社会保障 / 妊娠・育児 / 行政手続き |
| 対象読者 | 日本在住の妊娠中・育休取得予定の方、その家族 |
| コンテンツ形式 | インタラクティブ判定ツール（フォーム入力 → 結果表示） |

---

## 3. 掲載しないコンテンツ

本サービスは以下のコンテンツを掲載しません。

- アダルト・性的なコンテンツ
- 暴力・差別的な表現
- 違法行為を助長する情報
- 虚偽・誇大な医療・法律情報
- ギャンブル・賭博関連コンテンツ
- 危険物・武器関連コンテンツ
- 政治的な主張・選挙運動

---

## 4. 広告掲載に関するポリシー

### 4-1. 掲載する広告

本サービスは **Google AdSense** の自動広告を利用します。Google のアルゴリズムによりコンテンツに適した広告が表示されます。

### 4-2. 広告の適切性

本サービスのコンテンツは主に以下の文脈で利用されます：

- 妊娠・出産を控えた方の手続き確認
- 育休取得を検討中の方の事前調査
- 家族（配偶者・パートナー）が代わりに確認するケース

これらのユーザーに不適切な広告（例：過度に煽情的な表現）が表示されないよう、AdSense の広告審査設定を活用します。

### 4-3. 広告の配置

広告はコンテンツの可読性を妨げない位置に配置し、コンテンツと広告が混同されないよう視覚的に区別します。

本サービスが参照している法令・制度情報は、厚生労働省・ハローワークの公的情報に基づいています。判定ロジックの根拠となる情報源は `Rule.md` に記載しています。

## 6. 免責事項

本サービスの判定結果はあくまで参考情報です。育児休業給付金の受給可否は最終的にハローワーク（公共職業安定所）が判断します。本サービスの利用によって生じたいかなる損害についても、運営者は責任を負いません。
