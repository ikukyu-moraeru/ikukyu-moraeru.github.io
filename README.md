# 育児休業給付金 支給要件判定アプリ

日本の **育児休業給付金（および出生時育児休業給付金）** の支給要件②「みなし被保険者期間 12 か月」をブラウザ上で判定するための静的ウェブアプリ。GitHub Pages にデプロイ可能。

判定ロジックの仕様は [Rule.md](./Rule.md) を参照。

## セットアップ

```bash
pnpm install
pnpm dev      # 開発サーバ
pnpm test     # ユニットテスト
pnpm build    # 本番ビルド
```

## 構成

- `src/domain/` 判定ロジック（純粋関数・UI 非依存）
- `src/ui/` React コンポーネント
- `Rule.md` ドメイン仕様（公的ソース由来）

## 免責

最終判定はハローワーク（公共職業安定所）にて行われます。本アプリは参考情報であり、結果の正確性を保証するものではありません。
